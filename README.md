# 댕로컬 (PetMap)

반려동물과 함께 떠나는 미션형 로컬 여행 플랫폼입니다.

## 개발 환경

- Expo 57
- React Native
- TypeScript
- Expo Router
- Supabase

## 실행 방법

1. 의존성을 설치합니다.

   ```bash
   npm install
   ```

2. `.env.example`을 참고해 `.env`에 Supabase 프로젝트 정보를 설정합니다.

3. 개발 서버를 실행합니다.

   ```bash
   npm start
   ```

네이티브 지도와 위치 기능은 Expo Development Build에서 확인해야 합니다.
